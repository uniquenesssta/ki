## 核心方向

干净、自然、准确，好读但不干。保留人物当下盘算和真实幽默，不反复解释已经成立的结果。成长要实际改变主角能做什么；让他主动追求值得获得的东西，不只补故障、被追赶或赶期限。

长篇动力是军团征战回馈＋古甲进化。修复是前期重要手段，不是霸主阶段仍亲手修每个零件。基础供能前五十章内稳定后台化。星际与无限续航是后续展开空间，不因此锁定每章或终局。

## 记录边界

- 已发生：现行正文中的行为、交易、能力、数量、人物实际知道的信息。
- 新续写：本轮写出并提交的章节，不冒充用户逐章评价。
- 灵感：可以改、合并或放弃，不反过来命令故事。
- 历史稿：旧第四至二十章已归档；旧反馈有日期，不作为相反的当前指令同时生效。

《成神》保持独立开局与既有正文，本轮不改。
