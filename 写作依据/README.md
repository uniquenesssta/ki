# 写作依据

目的：每次动笔都能重新找到已经认可的阅读感觉，不依赖模糊的聊天记忆。这里不是剧情总纲，也不是让人物照表行动。

## 每次写作的阅读顺序

1. 先读 [因果与信息铺垫](因果与信息铺垫.md)，确认本次事件从最初起点建立，再读 [文笔与叙事](文笔与叙事.md)、[故事推进](故事推进.md) 和 [样本与反例](样本与反例.md)，实际重读认可的正文，不能只读评价。
2. 读对应的 [军团当前依据](作品/军团.md) 或 [成神当前依据](作品/成神.md)，再读本次承接的上一章及涉及的相关章节。
3. 需要处理阅读入口、目标承接或期待兑现时，查 [全量审计结果入口](../全书叙事审计/审计结果/README.md)及[使用方法](参考叙事审计/README.md)，再选择相关逐章记录或跨章链路；不必每次通读整份审计，更不能照原作章节顺序套情节。
4. 执行 [续写与验收](续写与验收.md)。需要哪项事实就查哪项，不通读一大堆无关设定拖住创作。

## 三种记录不能混用

- **已确认依据**：用户明确要求，以及当前认可正文中已经发生的事实。改动时要处理前后影响。
- **待修正文**：已经写出但未获认可或已被指出问题的稿件。可留作素材，不强迫新稿沿其路线走。
- **灵感**：可能采用、改造或放弃的方向。存放在两书各自的灵感文件夹，不升级成必须完成的任务。
