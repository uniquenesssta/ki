# 写作依据

目的：每次动笔都能重新找到已经认可的阅读感觉，不依赖模糊的聊天记忆。这里不是剧情总纲，也不是让人物照表行动。

## 当前认可定调 · 2026-10-23

用户在扩展阅读前160章并交付重写版后确认：“终于差不多对了 定调就这么来 后面也要这样子来 这160章没白读啊。”

后续文笔与叙事节奏以[本次认可第一章固定快照](https://github.com/uniquenesssta/ki/blob/81369c12c7b0fe547840287153e8418c5a0bbe83/军团/章节/第一章.md)为直接校准样本。每次续写实际重读该样本及承接章节，再按需要读参考TXT的后续连续场景，不能退回仅看前三章。

- 保持自然叙述、清楚因果、人物当下盘算、适度幽默与实际事件推进。精炼不是只剩动作，也不是删掉让读者明白处境、动机和收益的必要交代。
- 认可的是阅读感觉，不是固定结构；后续不复制同一开场、冲突、获益或收尾，不将每章写成同一套模板。
- 此次定调不等于第二至二十章已通过，也不锁死未来情节、能力终局与灵感。第二章起仍需重新衔接。

## 每次写作的阅读顺序

1. 先读 [因果与信息铺垫](因果与信息铺垫.md)，确认本次事件从最初起点建立，再读 [文笔与叙事](文笔与叙事.md)、[故事推进](故事推进.md) 和 [样本与反例](样本与反例.md)，实际重读参考TXT后续连续正文，不能只读开篇或评价；最新文笔参照与范围见[扩展复读](参考叙事审计/文笔与叙事扩展复读.md)。
2. 读对应的 [军团当前依据](作品/军团.md) 或 [成神当前依据](作品/成神.md)，再读本次承接的上一章及涉及的相关章节。
3. 需要处理阅读入口、目标承接或期待兑现时，查 [全量审计结果入口](../全书叙事审计/审计结果/README.md)及[使用方法](参考叙事审计/README.md)，再选择相关逐章记录或跨章链路；不必每次通读整份审计，更不能照原作章节顺序套情节。
4. 执行 [续写与验收](续写与验收.md)。需要哪项事实就查哪项，不通读一大堆无关设定拖住创作。

## 三种记录不能混用

- **已确认依据**：用户明确要求，以及当前认可正文中已经发生的事实。改动时要处理前后影响。
- **待修正文**：已经写出但未获认可或已被指出问题的稿件。可留作素材，不强迫新稿沿其路线走。
- **灵感**：可能采用、改造或放弃的方向。存放在两书各自的灵感文件夹，不升级成必须完成的任务。
