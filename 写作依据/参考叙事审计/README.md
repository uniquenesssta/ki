# 如何使用这份参考叙事审计

## 范围与性质

参考：用户提供的《这个游戏不对劲，我挖矿成神！》TXT。本轮逐章审计前20章，服务于开篇阅读入口、近期目标、跨章因果和期待兑现；不是全书逐章审计，不把早期规律直接推广到中后期。

这是一份编辑分析，既不是原作梗概替代品，也不是《军团》的强制大纲。它记录“为什么这件事让人愿意继续看”，不要求《军团》复制事件、人物关系或章节顺序。原作全文不存入本仓库。

用户最新判断：现稿文笔和剧情推进暂时没有大问题，但读起来一头雾水、投入不足。本轮只建立对照依据，不重写正文，不据此宣布现稿已彻底解决问题。

详细记录：[前20章逐章与链路](前20章逐章与链路.md)。

## 三种东西分开看

- 原文事实：本章人物做了什么，得到了什么，知道了什么。以正文为准。
- 编辑判断：这件事可能如何影响阅读期待、理解成本和情绪。不是对全部读者心理的事实断言。
- 可借鉴方法：移植因果与信息安排，不移植具体剧情。原作的受压迫开局、羞辱性配角、反复解释等，不因有效就自动适合本书；用户的禁忌仍然优先。

## 写前：只找一个相似问题

1. 重读《军团》当前上一章，先用普通话说明：许衡现在最想得到什么？读者为什么应该在意？
2. 找参考中功能相近的章节或因果链。例如“发现优势后怎样让人想继续获得”，而不是“轮到第几章，就照原作第几章安排”。
3. 用两三句话写出本次打算改变的东西。说明它为什么由前文引出，并给后文留下什么实际条件。无需给所有场景填表。

## 写后：用正文而不是口号验收

- 不认识专有名词的读者，能否说出眼前目标、机会和风险？
- 读者在机制被解释以前，是否已知道它能帮主角获得什么？必要背景不能为了“干净”而删没。
- 主角是否作了选择？选择与结果是否改变了之后的行动，而不是发生完一件事就清零换任务？
- 这次的好处有没有被人物感受到或用出来？是否只有参数变动和未来承诺？
- 章末续读理由能否从本章结果自然长出？不强制悬念句、突袭或新敌人。

不要求每章同时满足全部功能。跨章事件可以分阶段推进，安静场景也能改变关系、判断和计划。凡分析与实际阅读感受冲突，应回到正文验证，不用审计表替作品辩护。

## 《军团》当前的对照入口（候选修法，不是正文事实）

- 第一章已经给出装甲与仓库中的更多构装，后文应让读者持续记得“这些东西能怎样改变他的处境”，而不只记住一批待维修的物件。
- 第二章的征战回馈，重点可落在“亲眼看到第一具重卫替自己赢来成长，于是想拥有更多同伴战力”；构造和边界只解释当前判断所需部分。
- 第三章拆卸计划的威胁，需要建立在读者已经想看他带出更多构装的基础上。拆的是他的下一步希望，不只是地图中的一个地点。
- 暂不据此添加战斗、强行升级、立刻扩军，也不改变现有能量与交易账。具体改法须结合用户下一次要求和原章处理。

## 后续怎样扩充

前20章核对完成后，下一批优先选取目标转向、成长方式升级、角色关系兑现等关键段落，再决定是否补齐完整连续章节。不为“审计全书”堆积近千章摘要。

新增记录应注明章节范围、实际重读状态及尚未兑现的线索。当前20章之外的结果，不能靠印象补成事实。正文每次改动后只更新本书已发生的状态；参考审计不必随之膨胀。
