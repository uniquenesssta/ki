## 怎样使用

先确定当前写作问题，再查功能相近的章节与因果链，必要时回原文。不要照原作章序换名套用，也不要把角色猜测当已经验证的世界规则。

本审计只针对提供的材料。第996章断于句中，回家机制、公司的本质、罗开永久死亡、四皇子登基、斗宝胜负等未能在材料中结清；相应状态已登记。未解不等于作者遗忘。
