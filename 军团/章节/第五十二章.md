# 这趟穿越，我带了一支军团

## 第五十二章　先把人抬出去

被困的人在第二层。

许衡踩着翻卷的船壳进去，先闻到一股热油味。两盏应急灯挂在舱壁上，照着满地碎玻璃。前面一个船工抱住歪斜的扶手，衣服被铁皮扯开了，从肩头一直裂到腰。

“几个人？”

“七个。两个躺着，老秦的脚还压在下面。”

船工朝舱门后指了指。许衡侧过头，看到一个头发花白的男人靠坐在柜旁，左腿伸进变形的门框里，脚踝以下看不见了。旁边两副临时担架用窗帘裹着人，其中一个胸口几乎没有起伏。

许衡没急着让凿锤兵搬梁，先看门框上面。

整块甲板向这里塌了一角，几根管线绷得笔直。压住门框的梁一动，上面那层也会跟着走。

“顶撑拿来。”

邹诚从船腹递进两副螺旋撑，许衡让二号与十一号托住梁底，二十五号将撑柱送到受力的位置。他蹲下去，看着柱脚压实，才让两面重盾一点点向上抬。

金属摩擦声沿着舱顶传开。

老秦的脸一下白了，双手撑着地，努力把身体往后挪。

“别动。”许衡按住他的肩，“先把脚松出来。”

古甲的指尖扣住压扁的门框。那截铁边已经卷成双层，他试了试角度，左手抵住旁边的座架，右臂向外一扳。

窄窄的缝隙张开了。

血沾在门框里面。船工趴下去，把老秦的鞋一点点退出来，鞋面已经压烂，脚背肿得吓人。

老秦咬着衣领，一声也没喊。

直到腿从门下拖出来，他才松开牙，吐出一口气。

“这船……还是新换的门。”

“门还能换。”许衡托住他的膝下，“脚别再试了。”

医护从外面钻进来，接过伤员。担架顺着刚清出的路往外送，许衡让两具轻盾兵卸下盾，分别抬住两端。铁脚踩过倾斜的舱板，担架几乎没晃，后面跟着的船工看得出神，差点撞上门沿。

船外忽然响了几声枪。

许衡借五十号的视野看过去。

裂甲兽又来了，这次没有都扑向侧梯。七八头贴着断沟边绕行，想从船尾下面上来。那里恰好是抬伤员的出口，两个空艇救援队员正在往担架上扣吊带。

三号带着四名轻盾兵转过去，盾沿落地，挡住沟边的缺口。枪手从它们身后绕到略高的石面上，两侧交叉开火。

一头裂甲兽贴地跃起，前爪抓住盾顶。

持盾的新兵被撞退半步，脚跟随即抵住石缝。三号的刀从盾边递出，捅进兽的颌下，另一具轻兵同时抵上侧盾，把兽头夹在了中间。

尸体落地，后面那头当即往旁边转。

六号的机枪已经转向那里。

一串弹点追着它扫过沟边，兽背的硬鳞崩起碎片，终于滚了下去。余下几头退回黑草，吊索没有停。

许衡收回视野时，最后一副担架已经抬到出口。

巡空艇悬在上方，吊绳绷紧。担架慢慢离地，旁边的救援队员扶着边框走了几步，等它越过破舷，才松开手。

舱里的七个人，一个不少。

许衡顺着扶手爬上外侧，甲靴落到石地。救援队长在空艇上朝他举了下手，随即转身去接最先升上去的伤员。

这一趟空艇装满了。

剩下能走的船工由地面车送走，老秦坐在车边，腿下垫着折好的外套，还在叫人看后舱。

“里头冷柜漏了！别拿明火烤，白气有东西！”

裴岑已经带医械技师到了船腹，听见这句话，停住脚步。

“哪只柜？”

“后排，靠右。我下来关过阀，关不住。柜角给梁扎穿了。”

技师打开随身的小灯，从船腹破口往里照。更深处的货舱向下斜，一缕白雾贴着地面流出来，散到外面的黑草上。几只裂甲兽隔着盾列来回走，鼻子压得很低，正沿白雾留下的方向嗅。

技师捡起一块破木片，沾了些地上的液滴，远远闻过，立即放进密封袋。

“培养液。”他站起来，“银髓的外层封存液也有这种味，得进去看，光闻分不出是哪一批。”

许衡看向远处。

先前散去的兽并没有走远。石脊后面又露出几片黑背，数量比他们刚到时多了一倍。

“把柜拖出来会怎样？”

“破口不封住，拖到哪儿漏到哪儿。”技师指向自己提着的箱子，“能补，但我得看见破口。”

许衡让四十一号与四十二号分开守住船腹外侧，两门长炮车停到能覆盖石脊的硬地上。新枪手留下四名，另四名去护伤员车撤出。

裴岑抬头看了眼远去的巡空艇。

“人已经出来了。现在撤，救援的钱照结。”

“柜里有你要的货，也有我要的。”许衡看了看船腹，“先看能不能取。真撑不住，我比你跑得快。”

裴岑低头瞥了眼自己的靴子。

“这倒不用强调。”

许衡笑了笑，带她与技师进了货舱。

货物被绑在两列铁架上，倾斜时挤到一边。靠门的木箱裂开，铜管散了一地，再往里，几只银灰色封存柜用粗链扣在舱壁上，其中一只被断梁刺穿，柜面不断冒出细密的水珠。

技师用灯照过封签，脸色缓了些。

“不是银髓主柜。运输时附带的养护液，漏掉一些不影响里面封好的料。”

许衡刚让二十五号上前，脚下忽然一沉。

吊着后舱的梁发出一声长响，货架朝断沟方向滑了半尺。铁链猛地绷紧，裴岑被带得向前一扑，许衡伸手拉住她肩后的衣领，将人拽回自己身边。

一只木箱越过脚边，撞破薄舷，落进了下面的沟里。

几息之后，才听见箱子碎开的声音。

许衡向后看了一眼。

门还在，通道却窄了一截。

“柜先别拆。”他松开裴岑，让二十五号把肩顶到主梁下面，“把链子都接到陆舟上。”

“你想拖整段？”

“再拆下去，它要替我们卸货了。”

外面的炮声响了。

许衡从四十一号那里看见一片翻起的黑土。刚刚爬上石脊的几头裂甲兽被炸散，后面却还有黑影不断往上挤。

他将古甲的脚跟卡进地板裂缝，伸手抓住第一根粗链。

“梁平，车头转过来。”
