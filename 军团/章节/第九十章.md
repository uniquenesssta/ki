# 这趟穿越，我带了一支军团

## 第九十章　借一块甲板

护航舰左舷靠住缓冲架，右侧悬在外面。

秦瑛将长昼停在它炮口转不过来的尾下方，派出牵引缆，先扣住一根已经变形的外梁。铁棘另一侧也放出缆索，两艘船将这具仍在挣动的铁壳固定住。

许衡等舰身不再晃动，才让三号从通道口探路。

那条通道原本用于船坞维修，末端有伸缩接头，能直接贴在船侧检修口上。眼下护航舰歪了，接头与舱口差着大半个人高。

邹诚远远看了一眼，开始指挥人调下面的支架。

“还能对上。别让船再动。”

敌舰的腹部忽然打开两块小盖。

几具带外作业脚扣的守备兵爬出来，朝缆索移动。其中一具抬起切割器，刚搭上绳股，就被八十六号的一发短炮打离舰腹。

其余几具分向两边。

四名原炮卫沿长昼作业口依次开火，四枚短弹打碎两处外板，守备兵被压回舱口。八十七号又向盖板内补了一炮，里面的灯灭了。

牵引缆保住了。

通道接头终于贴合船侧，邹诚让人缓慢加压，确认压力稳定，才打开前面的内门。

这一次许衡带着八名盾卫与枪卫先进入。

护航舰内部比长昼紧凑。走廊两侧是管线与工具柜，通往中层的梯口只能容两名战卫并肩。尽头的防御枪刚抬起来，八十五号的大盾便堵住了半条走廊。

许衡贴着盾后向前。

枪声沿着金属通道震得头罩嗡嗡响，八十五号踩着地上的防滑条，一步一步顶过去，盾面上绽开一串明亮的火花。

到近处，十一号从侧面冲出。

重锤撞弯枪架，许衡随即割断下方供线。枪管垂落，他让后队沿楼梯上去，自己顺着地上的标线找舰内联锁室。

这艘船的守备没有一个人在喊话。

敌兵受伤也不退，只要还能活动，就继续执行封锁。许衡的军团把一处路口压住，它们便从另一条通道绕来，不断试图重新围住接驳口。

二十多分钟后，白塔已经占下两层舱室，前队却停在一道厚重的门前。

门后是反应舱外廊。

从三号探进去的视野看，里面有两具比普通战卫高出近一倍的重装，肩与胸连成斜面，后方的束缆直接接在墙上。它们不需要离开，守住这条廊就能护住舰内的主要节点。

“这门大，后面的路也大。”赵序在图上画了两笔，“就是过来的通道小。”

许衡看着舱图，忽然问：“外面能不能开？”

邹诚放大了舰腹的一块装甲。

“重械检修盖。能拆，但得先封住这里，免得把我们这两层气也抽走。”

许衡让队伍后退，隔离两侧气密门。

长昼下层的重械舱打开。

一百三十九号站了起来。

它已经很久没有机会把腿完全伸直。山岳式巨装走到舱沿，左臂的大盾竖在身侧，背后的吊带被绞盘绷紧，缓慢送向护航舰腹部。

两舰间没有宽阔的地面。

秦瑛让人先铺上两根检修承梁，给巨装的脚扣找到落点。它一步踏过去，梁面弯下一个清晰的弧度，固定扣接连收紧，将重量送回两侧舰体。

许衡从里面看着检修盖。

外面的扣件依次断开，一只巨大的铁手探进缝隙，抓住盖板边缘，将它向外掀起。

反应舱外廊的空气卷着碎屑冲向缺口，隔离门上的压力灯迅速转红。

两具守备重装同时转身。

山岳的大盾已经压进来了。

它借着外面的固定梁撑住身体，盾边撞上第一具重装的肩，将对方顶离墙根。束缆被拉直，重装拼命稳住脚，山岳却又往前压了半步。

墙后的固定座被整片扯出。

另一具重装抬起武器，九十号与两名带外作业锁扣的盾卫从侧面扑进，压住它膝下的空处。许衡关闭面甲，进入失压外廊，沿着山岳盾后让出的窄缝贴近。

新甲的细架扣住他的腰背，头罩内只有呼吸声。

他蹬住重装弯下的膝部，将腕刃送进颈下接口。亮刃穿透薄弱的连接层，观测眼随即熄灭，巨大的身体倒向一旁，被山岳的盾接住。

第一具还在挣动。

山岳腾出右手，抓住它的肩架，把它从断开的墙座上提了起来。

许衡停在它胸前，将里面的主供线切开。

外廊安静下来。

那两具曾经能将整条通道堵死的重装，被摆到了同一面墙边。山岳松开盾，继续站在检修口外，替后面的维修队托住拆下的盖板。

赵序隔着门窗看了半天。

“这家伙的工钱，不能按搬运算。”

许衡打开联锁室外面的控制盖，看见里面还在运行的指示灯。

“先让它托稳。今晚有一整艘船要搬。”
