# 这趟穿越，我带了一支军团

## 第四十五章　让他们打空地

响石堡外的第一炮，落在陆舟前面。

土从路上掀起，砸到观察窗外沿。梁平立即松了操纵柄，谭峥留下的辅助司机探头看路，发现弹坑占了半边，另一半却还连着一段坚实的旧路基。

“能绕。”

许衡点头，让车沿外侧压过去。

陆舟的前履带越过坑沿，后面的几组履带接住重量，车体只向一边沉了一下，便重新平稳。装在舱里的重卫没有散，腰部固定扣牢牢锁着，只有供能臂上的细链轻轻晃了几下。

换成原来那辆货车，许衡现在该下去填坑了。

他望向远处的堡墙，让梁平继续向南侧低地开。

北岸的队伍在后面分开了。

这次陆骁并非只带采办队。前线调来的一支加强连由陶晋领着，步兵、工程班与三门轮炮都到了，另有两辆披甲车守住侧面。他们在路口停下，先让炮展开，没有紧贴着陆舟的尾门跑。

大家都知道，前面那座堡不是空地上的一辆炮车。

响石堡建在高出河谷的一片岩台上，主门朝南，北面连着军用堆场。东侧有两座交错的炮位，西边是沿山挖出的运输沟。堡墙不算高，却厚，炮口的下方还堆着一层石料，正面不容易砸透。

许衡早看过司机们画的重货路。

他没有叫陆舟冲主门，而是沿南面那片低地横过去，让土脊渐渐挡住对面的炮口。车体沉入低地时，第二发炮弹从头顶掠过，落在后面的空路上。

“停这里。”

许衡松开舱内固定扣，侧门随之向外落下。

四具炮卫最先出来，沿门侧分向两边。支撑盾沉入地面，肩炮向上抬，后面的普通重卫踩着侧梯下来，厚盾一面接一面立起，将炮位前方护住。

二十五号与二十六号从尾门走出，凿锤垂在身侧。

三十二具钢铁躯体，在土脊后展开了。

堡上的人看见陆舟停住，原本还以为它要等步兵跟上，直到最后几具重卫跨出尾门，炮口才开始向这一片低地偏转。

可它们打不着地面下方的人。

许衡站在陆舟侧门内，等三号沿运输沟往前探。沟里有旧轮痕，几处崩塌已经被人清过，上方还搭着简单的遮雨板，说明堡里的人正在用这条路运东西。

这是一条能靠近堡墙的路。

也是对方一定会守的地方。

三号走到第一个转弯，看见沟口压着一辆斜放的盾车，车后两挺枪左右错开。再往上是半截栅门，几个人正推着木箱来堵，想趁炮还没落过来之前，把这条路封死。

许衡想让六号上前，脑中三号的视野却忽然晃了一下。

它已经离开陆舟很远，中间又夹着土坡与堡基。许衡刚要改成让它退回近处，邹诚便从驾驶舱边探出头，指了指墙上的一块小表。

“船上的队用讯塔没升，要不要开？”

许衡抬头。

这几天他见过那组接头。谭峥交机时说过，兵舱固定座旁还有与控制端相连的队用通讯线路，原来供整舱构装离舰后交换位置与命令。普通驾驶员只能借它通话，许衡一直没在远处用过。

“升起来。”

邹诚压下开关。

陆舟背部一根短塔缓缓抬起，几片窄板向外展开。许衡将左掌贴上侧门内的军用接位，原本只连着车体的结构向外延伸，三号那幅迟缓的景象，忽然变得清楚起来。

沟口那辆盾车上的铆钉重新清晰，栅门旁一名士兵正探头望向外面。

许衡试着让三号低下身，它立即伏在沟侧，枪弹从原来站着的位置掠过，打碎了一片旧雨板。

他笑了一下。

这艘船带来的，不止是坐兵的地方。

“六号走左边，四十一跟盾过去。三号别露头，等它们到。”

队伍沿运输沟移动，另外两组仍留在陆舟两侧，看住从堡外绕来的方向。许衡能把注意从沟口移回炮组，不必为了看清三号，就亲自再往前走一段。

陶晋的第一轮炮火此时落到了堡东。

三门轮炮不求一炮轰穿墙，只盯着两个敌炮位之间的遮挡，一发接一发砸下，逼得炮手缩回里面。陆骁沿土脊过来，看见许衡的盾列已经接近运输沟，便让北岸步兵从另一侧展开。

堡里的人开始往主门调兵。

一队穿甲步兵从门内跑出，先看见的是北岸的旗，刚要向路口压，侧面便响起了六号的机枪。

他们立即伏低，沿墙退回半步。

许衡没让六号追人，转而让四十一号对准沟里的盾车。炮卫在盾后站稳，一炮打在盾车下部，轮架碎开，厚板朝沟里栽倒，把后面那挺枪压在了下面。

四十二号跟进，第二炮打向栅门旁的石墙，将藏人的角落掀开。

二号踩过倒下的轮架，重盾顶住半开的栅门，向里一推。

栅门后堵着的木箱被推得滚开，几名兵连忙往两边躲。三号从盾旁穿过，刀背压住最近那人的枪，五号则看住另一侧台阶，不让对方绕到二号身后。

许衡从侧门下去，古甲贴着身体收紧。他沿已经由重卫护住的沟道向前，跨过倒盾车，站到了响石堡的外墙下。

身后，陆舟的侧门仍开着。

四十三号与四十四号守在土脊旁，炮口随着堡上枪位的变化调整。远处的火力不必再等许衡回来逐一搬动，仍按原来的任务护住出舱通道。

许衡看见前方墙上伸出一只短炮口，立即让二号压低盾，同时转到三号给出的另一侧视野。

炮管后面，有一条向内斜下的装弹道。

“二十五号，往这里来。”

他抬手指向那段承着炮位的外墙。

“这回，把下面拆开。”
