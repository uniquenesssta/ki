# 这趟穿越，我带了一支军团

## 第十八章　让它亮起来

缆索绷紧，挡在北门前的盾障往后收了一丈。

顾柏没有让人去夺回东炮。他把剩下的护卫往西侧收拢，宁肯空出半边门，也要保住仍然能开火的那门炮。

许衡看见炮座后面多了两个人。

他们没有举枪，而是各拿一根长柄撬杆，准备在他靠近时卡住关节。炮位四周的地面也让了出来，所有人都知道，挤在一起只会妨碍装填。

对方还没乱。

许衡沿石墩走了半圈，停在吊运坑边。

他最想要的也不是对方乱。

是让他们来不及。

一号先解开墙边牵引座上的尾链，松开轨车制动，再把牵引链最后一段送了出来。许衡弯腰将它从缴获炮架的底梁穿过，扣进轨车低处的吊耳，又指向石墩后的旧制动柄。

“等我松手，再推。”

西桥上响起枪声。

一名枪手绕过栏墙，终于找到了东边的射角，却只打出一发，旁边石沿便溅起碎屑。南院的赵序与两个伙计没有追着露头，只隔着厚墙轮换观察，把那人压回了栏后。

他们挡不住整座高桥，能给许衡争出几步就够。

许衡没有浪费。

他冲出石墩，抬脚踩住地上的拖缆，双手扣着缴获的炮架向前一送。

沉重的炮与轨车一起滑出遮蔽，正挡在西炮的前方。

西边炮手没有开火。打穿同伴的炮座不难，打穿后是否还能碰到藏在后面的重甲，他没把握。长筒向左偏，许衡也随车挪了一步。

第二次偏转时，二号已经从大厅北口出来了。

它没有去撞盾障，而是握住许衡提前标记的那道缆索，将缆索压进卸载台边缘的旧系泊槽。三号把护板立到它侧面，偏转组件只亮起短短一瞬，拨开从西桥上斜落的弹片，便重新熄灭。

许衡抬手。

一号在石墩后全力推动轨车。

他的双臂也同时发力，把炮架向左横拖。几个人都搬不动的铁家伙沿着斜斜的旧轨转过半圈，底下缠住的拖缆被猛然带偏。

北门外，牵引车向前滑了半个轮位。

驾驶员立即放松绞盘，免得车被扯翻。那道原本贴着地面绷紧的缆索落下去，抽得石屑四溅。

许衡已经跨过去。

他从炮座后大步冲出，径直扑向西炮。

炮口跟着他转。

长筒很快，许衡却已经进到它转过来必定扫过的范围。他左手抓住炮架侧梁，右臂横撞上摇架，整个人往里压。

重矛在他头顶射出。

一道黑影穿过空荡荡的大厅入口，钉进远处没有设备的货座。厚重的石台被掀起半面，震响从脚下涌过，连穹顶残存的铜板也嗡嗡颤动。

许衡的头几乎贴在炮侧。

他的甲没有替他挡这一炮。

是他抢到了炮口下面。

一根撬杆照着他的膝弯捅来。他向前踏实，夹住杆身，把来人连同撬杆一起甩到旁边。另一人还想绕背，四号已经从南侧冲了上来。

四号不是擅离守位。

赵序确认西桥枪手开始撤退，南院不再暴露，许衡才给它下了前移的指令。三米高的铁躯越过已松开的缆索，左肩顶住炮位侧面的盾障，整片铁木夹板被它推得向后折去。

一根断裂的支杆刮穿它肩侧外板，卡在里面，仍没能让它停下。

二号从另一侧压住炮轮，三号的旧护板随后堵上缺口。

四个方向，在炮位前合成了一处。

许衡双手抱住炮架的横轴，向上一抬。

炮手惊叫着离开座位。

沉重的炮身翻起，底座从固定楔里挣脱，带出一片石粉。许衡没有把它砸向人群，而是扛着炮尾转过身，将整门炮掀过身旁的厚石沿，推向卸载台西缘空着的低层泊位。

铁轮越过台沿。

一侧炮轮卡在台沿的粗轨上，另一侧支脚撞住石边。炮架斜着陷了下去，前半截跌入低处，长筒朝下，再也照顾不了任何一个人。

许衡松开手，胸口随着呼吸剧烈起伏。

两门炮，一门断了装填托盘，一门卡在台沿下面。

还站在盾障后的护卫，看着向自己转过来的重卫，没有再试着扣动扳机。

“放下。”许衡说。

第一支枪落地，随后是第二支。

顾柏站在北门外，望着那座古旧的卸载台。他的人还能撤，牵引车也还能走，但阵地已经不属于他了。再让护卫填进去，换不回那两门炮，只会把往后还能用的人也丢掉。

他举起手，让剩下的枪口朝地。

“停手。”

许衡没有追出北门。他让二号守住收缴武器的地方，三号仍护着大厅通路，四号退到门边压阵，自己先确认西桥上最后一名枪手撤出了射界。

一号才从东廊出来，将卡在轨道上的破架拖开。

一号的薄护板上挂着石灰，二号胸前满是斑驳的新弹痕。三号收着发热的肩环，四号左肩还卡着半截断杆。

许衡依次确认了它们的回应。

四具，一个不少。

许衡回到大厅时，唐芮正站在调度台旁。

“可以了？”她问。

“北面不会再有炮打进来。”

她看了一眼他的肩甲，没在这时候追问，转身让帮工去看下层标记。

启动不是许衡按一下，整座站就听话亮起。

唐芮让他先接通已经检验过的运行位，自己看着六座支架的反馈。一个接点比其他地方慢，她便停住下一步，等那道锁舌确实退入槽内，才让许衡继续。

下沉大厅里，暗金色的外环开始转动。

最初几乎看不出来，只有护板上的一条旧伤缓缓越过支架。随后，环内的细槽一层层透出暖白的光。沉睡的庞然大物没有喷出火焰，也没有冲上天空，六座支架稳稳地承着它，将越来越清晰的低鸣送入地底。

穹顶下的检修灯接连亮起。

光越过剥落的石柱，越过被炮击碎的货座，照到北门的古徽上。那些磨平了面容的浮雕行列，第一次有了清楚的影子，仿佛沉默多年的军队重新站到了自己的长桥边。

许衡没急着看它们。

他盯着调度台，直到唐芮的手从最后一处回检标记上移开。

“稳定了。”

他们又让设备连续带过几轮实际负载。维修院的吊臂平稳抬起，工间的灯没有暗，几只送进标准补能座的旧匣依次亮满。

输出始终稳稳停在预留范围内。

炉体内封存的工作介质和循环部分完整，外部需要定期维护的是支承、接口与耗损件，不必每天往里塞一车买来的供能匣。唐芮把这一点说得很清楚，许衡也终于放下了一件从第一天就压在心里的事。

不是又捡到一批能用到下次的存货。

是从此有了持续的来处。

日常供给、这几具重卫、维修平台以及修造仓的补能转运，都在现在的稳定余量以内。以后要扩多少，得看材料、人手和设备，不必每走一步先求人卖一只匣子。

许衡走到栏边。

下方环炉缓缓转动，光落在他伤痕累累的护肩上，把深沟里的暗金色纹路一寸寸照亮。

第一次穿上这身甲，他抢来一只供能匣，才敢继续往外走。

现在，这身甲身后，有了一座亮着的车站。
