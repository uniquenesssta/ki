# 这趟穿越，我带了一支军团

## 第九十八章　四百零一个

两艘船回到七区时，韩岳先在船坞里站了十多分钟。

老人没有急着看最贵的机器，而是沿检修梯往下走，摸过几处轴座，量了装配台的基准面，又抬头看了看吊架的最大行程。

最后，他只问邹诚要了一间能放工具的屋子。

第二天，那间屋子的门就一直开着。

地面来的工匠与原来留厂的人混着分组，白班做装配，后半班检查已经下线的战卫。韩岳不让人只盯着表格上的合格标记，每次都抽出几具，换臂、负重、跑窄道，哪里有偏差，就沿着前面的工序倒回去查。

三周的交期没有拖。

最后一批外板装上时，车间外的空场已经划好了队列位置。

许衡站在最前面，看第一具新战卫从门里走出来。

它比最初捡来的重卫矮一些，身上的线条也更紧凑。胸口没有旧军徽，只在新漆下面留着白塔的编号槽。

二百七十四号。

六十四具刀盾兵与六十四具枪卫依次出厂，枪口统一向上，刀刃收在盾侧。四百零一号走到最后一排时，许衡让整个队列同时向前一步。

脚步声在空场上叠成一记低沉的闷响。

原来的两百七十三，加上眼前这一百二十八，白塔已有四百零一个。

四百具常规战卫，一具山岳。

许衡把队列分成四组，依次穿过两条宽窄不同的通道。一组在前面架盾，另一组从侧面换位，枪卫越过半人高的模拟障碍，最后将一具假定受损的同伴拖出交火线。

没有谁在狭门里卡住，也没有为绕开盾缘把后排枪口带偏。

邹诚站在控制台旁，将最后几项实测写进验收单。韩岳看完，拿起印章，稳稳盖在末尾。

这批兵算是交到许衡手里了。

旁边另一条线上的八台装卸机，也在同一天交付。

货运主管带来自己的操作员，仍是上回戴护套的那个人。他摸过夹具下的软垫，先试急停，又把一框玻璃管件抬到货台最高处。

货框放下，里面没有响一声。

主管签了验收，付清剩余两千四百银。许衡让赵序把机器编号、备件清单与检修日期一起交过去，装车时还留了两包可以自己更换的软垫。

第一份厂里的订单，收完了尾款。

扣去回地时已付的八名工匠首月三百二十银，再加这笔尾款，白塔手里有五千四百五十三银。许衡又将到期的邹诚、于卓船务组、秦瑛与副手工钱，以及地面电站的下一月费用一并结清，共一百五十二银，余五千三百零一。

许萍收到送回的单据，只回了两行。

验收单留好。

这回没漏。

赵序把纸折起来，松了口气。

“比别人夸我会开车还难得。”

新兵列好以后，许衡重新分了驻守。

地面原有二十具照旧，七区厂增到一百四十具常规兵，沿厂房、泊位、转运道各留独立小队。余下二百四十具常规兵与山岳组成随行军团，长昼载一百八十具常规兵及巨装，折锋载六十具。

两艘船都有自己的兵舱，不需要把整支军团挤进陆舟。

在厂期间，邹诚还带人将之前缴来的完整高射炮装进长昼预留的外侧炮位。转向线接好、限位调过，冯师傅用原配弹抽试了一轮，确认不会扫到旁边的接泊臂，才把炮衣掀开留在外面。

折锋的两座近防炮也完成了核配，试射后保留两条各二百发的可用弹带，另有空位还未装满。它们负责近处的小目标，不能替代船首主炮。

陆舟的舱门也换过密封件，梁平关门保压了一夜，第二天又和邹诚核了驾驶舱的循环。原来挂在舰腹往返的兵舱，现在可以在脱离挂架后，短时通过外泊台再接入密封通道；两侧的放兵板仍得等接驳压差归零才开。

许衡从长昼的炮位下来，看见唐芮正在下面等他。

她把一块修好的肩甲递过来，是山岳先前过桥时被打裂的那片。板边补得很平，旧弹坑仍留着一半。

“现在这儿能自己做这个了。”

许衡接过甲片，重量压得手臂沉了一下，伴生甲随即稳住。

从最早花几枚铜角找零件，到现在整条生产线能出新兵，大一点的外板也不必拆别人的来补。

他将肩甲送回重械舱，亲手扣在山岳肩上。

巨装缓缓抬臂，大盾从固定架上升起，刚换好的肩片沿关节滑开，没有碰到边缘。

这时，赵序从前舱下来，手里拿着一份矿料运输图。

是上次那艘拖船送来的。

货行愿意按月给七区供料，价格也报了。只是最近外侧一段旧航标路被人占着，空船过去收一次钱，满船回来还要再收一次，已经有两批货改道。

许衡把图铺开。

路线离七区不算远，一端连着矿场，另一端正接工厂的外运通道。

赵序指了指其中一处废泊台。

“我问过了。拦咱们那两条小艇，就在那里挂旗。”

许衡看了看窗外。

四百具战卫已经各自回到岗位，折锋的舰首正朝着出港方向。

工厂有了，兵也造出来了。

他不打算让下一批料，每到厂门前都先给别人交一笔过路钱。
