# 长篇网文 · 灵感库

这里放可以拿来试、改写、拼接或放弃的灵感，不是必须照做的设定手册。书名与方向均可调整。

希望读到的是：都市带一点穿越，轻松有趣，主角头脑清楚、有自己的脾气；开局有能力和冲突，升级有实在的优势与碾压，长篇能宏大展开。生活感不能代替主线爽点，数字在需要时说得清。

目前不想写：虐主、后宫、强行误会、频繁说话的系统、为了衬托主角而降智的配角。
