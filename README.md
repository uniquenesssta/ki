# 城市隐藏地图 · 灵感库

这里放可以拿来试、改写、拼接或放弃的创作灵感，不是必须照做的设定手册。书名与方向均可调整。

希望读到的是：都市带一点穿越，轻松有趣，主角头脑清楚、有自己的脾气；成长让人期待，人物有生活，数字在需要时说得清。

目前不想写：虐主、后宫、强行误会、频繁说话的系统、为了衬托主角而降智的配角。

## 怎么放

- `inspirations/`：空间、人物、幽默、成长等零散火花。有内容才建文件，不预先填满设定。
- `possibilities/`：把几个灵感暂时放在一起，看看可能长成什么故事。不是剧情承诺。

先前的具体能力、角色、剧情安排都只是候选，不因为写进文件就成为定稿。好故事可以推翻旧点子。

参考阅读：《这个游戏不对劲，我挖矿成神！》（道不易），用户提供的文本共 996 章。正在继续全文阅读；尚未完成全量整理。不上传参考小说正文，只保存原创提炼与灵感。
