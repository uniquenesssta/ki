# 共用阅读口味

这是阅读偏好，不是逐章检查表，也不是两本共用的剧情模板。

- 都市带一点穿越，轻松有趣，主角头脑清晰，有可靠、能兑现的金手指。
- 文字干净、老练、准确，描写适量。跟着人物的打算、发现、判断和感受推进，不像旁观者汇报经历。
- 普通动作、重复验证与已明白的结论合并带过；关键变化值得展开。提速不能把情绪、人情与趣味一并删掉。
- 爽点来自有效的能力、实在的优势、选择和战果。生活感不能替代冲突与成长，也不需要每场戏都打架。
- 配角有自己的能力、利益和生活，幽默从性格与处境里发生，不连续插俏皮话打断剧情。
- 两部故事可以同样好读，但开头、事件组织、叙事过程与发展方向必须各有特点。
- 不写虐主、后宫、强行误会、频繁说话的系统或配角降智。
- 数字在帮助判断时出现，写出的钱、时间、消耗和效果需要对上；不预先填写未来每章收益。

只保留灵感和有用依据，不让资料限制后续创作。共用灵感中的举例不是任何一部故事必须采用的设定。
